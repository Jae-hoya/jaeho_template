# Copy Input Guide

`/api/v1/copy/generate`의 자주 헷갈리는 필드를 빠르게 정리한 문서입니다.

## pain_point

- 무엇을 쓰나: 고객이 실제로 겪는 성과 저하 문제
- 좋은 작성: 문제 상황 + 지표 손실(CTR/CVR/CAC) + 긴급성
- 예시:
  - "CTR 하락과 소재 피로로 CAC가 올라, 같은 예산으로 확보하는 리드 수가 줄고 있다"
  - "A/B 테스트를 자주 해야 하는데 카피 제작 리드타임이 길어 최적화 타이밍을 놓친다"

## differentiator

- 무엇을 쓰나: 경쟁 대비 우리 제품의 성과 우위 근거
- 좋은 작성: 핵심 기능 + 데이터/근거 + 기대 성과
- 예시:
  - "LangGraph 기반 RAG+Tavily 결합으로 최신성과 정확도를 확보해 전환형 카피 제작 시간을 단축한다"
  - "내부 브랜드 자료와 시장 컨텍스트를 동시에 반영해 메시지 일관성과 채널별 반응률을 함께 개선한다"

## objective

- `brand_memory`: 브랜드 기억/인지
- `click`: 클릭 증가
- `add_to_cart`: 장바구니 담기 증가
- `consultation`: 상담/문의 전환

팁: 지금 캠페인의 1차 KPI가 무엇인지 기준으로 선택하세요.

## channel

- 무엇을 쓰나: 카피가 배치될 실제 채널/포맷
- 예시: `상세페이지`, `메타 광고 랜딩`, `인스타 피드`, `유튜브 쇼츠`, `이메일 캠페인`

팁: 실제 지면명을 쓰면 문장 길이/톤 최적화가 더 정확해집니다.

## language

- 무엇을 쓰나: 출력 언어 코드
- 형식: BCP-47 스타일 코드
- 지원: `ko`, `en`, `ja`, `zh-CN`, `zh-TW`, `es`, `fr`, `de`, `pt-BR`, `vi`, `id`, `th`

별칭도 자동 변환됩니다.

- `english` -> `en`
- `korean` -> `ko`
- `ja-jp` -> `ja`
- `pt-br` -> `pt-BR`

## top_k

- 무엇을 쓰나: RAG/웹 검색에서 참고할 근거 문서 개수
- 기본값: `5`
- 권장 범위: `3~8`

해석 가이드:

- 너무 작음(1~2): 근거가 부족해질 수 있음
- 적정(3~8): 핵심 근거와 다양성 균형
- 너무 큼(10+): 맥락이 퍼져 문장이 흐려질 수 있음
