### Chenious chat
- Multi LLM 응답 결과 비교 챗봇

- 2개의 모델을 받아서, 2개의 창에 2개의 결과물이 나오는 도구(agent)
- best 결과를 선택할 수 있게해서(ux 단에서) 
    - 그 결과를 return해서 대화할 수 있도록 함.
    - 계속해서 2개의 결과를 return함

- 입력
입력 텍스트 프롬프트 자연어 최대8000자 자유형 질문/요청
업로드 할 수 있는 개인데이터로는 pdf, doc, docx, txt, xls, xlsx, ppt, pptx, png, jpg
웹 검색 키워드: 검색 쿼리, 실시간 정보 수집을 위한 검색어

- 출력
    - 다중 모델 응답
    - 멀티 공유 가능한응답. json/md, doc/docx파일
    - 사용이력: 쓰레드 형싟의 개인 프로픔트 및 결과 관리

- 주요기능
프롬프트에 대한 최적 응답 제공

### Cleunt brief reader
- 목적
    - 브리프(PDF, PPT, DOC, DOCX)를 2분안에 구조화 및 요약하여 핵심 요구, 숨은 니즈 위험 요소 액션 리스트 제공
    - 광고주 브리프 문서 요약, 분석 및 제안, 클라이언트 정보를 받아서, 요약해주는 도구(agent)

- 입력
    - 파일 업로드(총 업로드 100mb이하) 브리프 파일 및 관련 자료
    - 일정 및 담당 스텝 관령 정보(text 입력)

- 출력
    - 목표, 과제, 제약조건에 대한 요약(text: doc 또는 md)
    - 암묵적 니즈 및 근거, 리스크 에 대한 예측(text: doc 또는 md)
    - 주요 차트(입력된 자료 거의 그대로 삽입: PNG, JPG)
    - 일정 정리, 담당 스텝(프롬프트 입력에 대한 출력)

- 주요 기능
    - 멀티 모달 모델을 통한 입력 자료에 대한 요약 및 해석
    - 리스크 요인에 대한 메트릭스 출력
    - 결과물 Export(PPT, PDF, DOC)

### 카피조
- 고객의 행동을 이끌어내기 위해 쓰는 모든 설득 문장 생성

- RAG를 받아서 사용할 수도 있음
    - RAG로 데이터를 받아서 카피 아이디어를 제공
    - file upload로 받아서 사용할 수도 있음

- 카피의 목적
    - 브랜드를 기억하게 하기
    - 제품을 클릭하게 하기
    - 장바구니에 담게 하기
    - 상담을 신청하게 하기

-  좋은 카피의 특징
    - 고객의 언어를 쓴다
    - 길지 않다
    - 구체적이다
    - 감정을 건드린다
    - 차별점이 명확하다

- 카피의 유형
    - 슬로건형 카피(브랜드 이미지를 각인시키는 문장)
    - 문제 해결형 카피(고객의 고민을 건드리는 방식)
    - 혜택 강조형 카피(결과를 먼저 보여주는 방식)
    - CTA형 카피(행동을 직접적으로 요구)
