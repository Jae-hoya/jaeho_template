### single file component(sfc)

Component를 모듈화 하는것.

vue와 

npm init -y (chrlghk)
npm install vue
npm install vite
npm install @vitejs/plugin-vue
npm run dev

실무에서는 다음과 같은 형식으로 Component를 파일로 정리한다. (모듈화)


```
export defalt{
    tempalate: '
    
    '
};
```
진입점을 main.js로 정리하고,
import 로 가져온다.

script에서 type='module'로 지정해야한다.

여기서 template를 문자열이 아닌 sfc를 하기 위해선 vue 파일 형식이어야 하고, 
template는 vue, script는 javascript, sytle은 css방식이 들어가는 것이다.


```
<tenplate> 
    <div>
        HTML Vue - HTML 마크업 정의
        사용자 ui를 선언적으로 표현
        Vue의 템플릿 문법(Mustache {{}}, 디렉티브 v-if, v-for 등)을 사용하여 JavaScript 데이터와 DOM을 바인딩
    </div>
</template>

<script>
    Javascript - 로직
    데이터 관리, 사용자 인터렉션 처리, 뷰와 데이터 연결
    TypeScript 지원 (<script lang="ts">). 
</script>

<style>
    css 스타일
    컴포넌트 전용 스타일 또는 클로벌 스타일 정의
    전처리기 지원: Sass, Less, Stylus 등 사용 가능 (<style lang="scss">).
</style>

```

css도 assets에 정리를 해서 불러오는 식.

main.ts 에서 npm vue run을 할때 뜨는 화면을 지정할 수 있다.
