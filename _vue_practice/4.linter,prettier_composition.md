vite.config.js 같은 파일에서 오류가 나는걸 확인할 수 있는데,
linter를 통해서 오류를 확인할 수 있다.

alias는 파일 시스템의 경로에 별칭을 만드는것
예를들어, @는 src파일을 가르키도록 하겠다 하는것이다.

alias가 없다면현재경로에서 상대경로를 넣는데, alias(@)가 있다면, 특정 별칭(src)을 뜻한다.

```
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    },
```
