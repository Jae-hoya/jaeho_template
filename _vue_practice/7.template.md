# template

template문법을 통해서 copoment instance 데이터 바인딩 할 수 있다.

## 텍스트 보간법 : {{ message }}
이중 중괄호를 통해서 메시지라는 데이터에 바인딩 할 수 있다.

## v-once: 
디렉티브를 사용하여 데이터가 변경되어도 갱신(변경)되지 않는 일회성 보간을 수행. 바인딩이 되어있어도 변경이 안됌.
```
<p v-once> 문자열: {{ message }} </p>
```

## v-html: 
{{ }}은 일반 텍스트로 해석을 하는데, HTML을 출력하라면 v-html디렉티브를 사용해야한다.
XSS취약점이 있어, 신뢰할 수 있는 콘텐츠에서만 사용하고, 사용자가 제공한 콘텐츠에서는 절대 사용하면 안된다
```
<template>
    <div>
        <p v-html="rawHTML"></p>
    </div>
</template>

<script>
import {ref} from 'vue'

setup(){
    const rawHTML = ref('<strong>안녕하세요</strong>')
    }

</script>
```

## v-bind: 속성 바인딩

{{}} 안에서, 자바 스크립트 문법도 사용 가능

v-bind:title="" : 마우스 위에 올리면 문구가 뜨도록 함
v-bind:disalbed="" : text가 있는데 값이 변하지 않도록. (true false 가능)
v-bind="" : 바로 객체를 넣음으로써 다중 바인딩.

```
<h2>v-bind 속성 바인딩</h2>
<div v-bind:title="dynamicTtile">마우스를 올려보세요</div> // 마우스 위에 올리면, 문구가 뜸
<input type="text" value="김재호" v-bind:disalbed='isInputDisabled' /> // text가 변하지 않도록
<input v-bind="attrs" /> // 바로 객체를 넣음으로써 다중 속성 바인딩 가능

const dynamicTtile = ref("안녕하세요!!!")
const isInputDisabled = ref(true)
const attrs = ref({
    type: 'password',
    value: '12345678',
    disabled: false
})        


```
