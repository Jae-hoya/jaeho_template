# 🚀 LangGraph PDF RAG 시스템 실행 가이드

## 📋 사전 준비

### 1. **의존성 설치**
```bash
pip install -r requirements.txt
```

### 2. **API 키 설정**
`.env` 파일을 생성하고 다음 내용을 추가하세요:

```env
# OpenAI API 키
OPENAI_API_KEY=sk-your-openai-api-key-here

# Tavily API 키  
TAVILY_API_KEY=tvly-your-tavily-api-key-here

# LangSmith (선택사항)
LANGCHAIN_TRACING_V2=true
LANGCHAIN_API_KEY=your-langsmith-api-key-here
```

### 3. **PDF 파일 확인**
- `data/SPRi AI Brief 7월호 산업동향.pdf` 파일이 존재하는지 확인
- 다른 PDF 파일을 사용하려면 코드에서 경로 수정

## 🎯 실행 방법

### **방법 1: 대화형 실행**
```bash
python langgraph_pdf_rag_ensemble_tavily.py
```

### **방법 2: 예시 코드 실행**
```bash
python example_usage.py
```

## 🔧 문제 해결

### **API 키 오류**
```
❌ OPENAI_API_KEY가 설정되지 않았습니다.
```
→ `.env` 파일에 올바른 API 키를 설정하세요.

### **PDF 파일 오류**
```
❌ PDF 파일을 찾을 수 없습니다: data/SPRi AI Brief 7월호 산업동향.pdf
```
→ `data` 폴더에 PDF 파일이 있는지 확인하세요.

### **의존성 오류**
```
ModuleNotFoundError: No module named 'langchain'
```
→ `pip install -r requirements.txt` 실행하세요.
