# Streamlit 앱 기능 소개

## 🎨 UI/UX 기능

### 1. 채팅 인터페이스
- **실시간 대화**: 사용자와 AI 간 자연스러운 채팅
- **메시지 히스토리**: 전체 대화 내역 유지
- **타임스탬프**: 각 메시지의 시간 기록

### 2. 라우팅 시각화
- **Route Badge**: 각 답변의 라우팅 결정 표시
  - 🟢 SEARCH: 검색 수행
  - 🟠 DIRECT: 직접 답변
- **실시간 표시**: 답변과 함께 라우팅 경로 확인

### 3. 검색 결과 표시
- **확장 가능한 섹션**: "검색 결과 보기" 버튼
- **상세 정보**:
  - 상품명
  - 상품코드
  - 금리 범위
  - 요약 설명
  - RRF Score

### 4. 사이드바 기능

#### ⚙️ 설정
- **디버그 모드**: 실시간 토글
  - 워크플로우 각 단계 추적
  - 자동 RAG 재초기화

#### 📊 시스템 정보
- RAG 상태 표시 (활성화/비활성화)
- 사용 중인 모델 정보
- 검색 방식 표시

#### 🔄 워크플로우
- ASCII 다이어그램으로 플로우 시각화
- 라우팅 경로 이해 지원

#### 📈 통계
- **총 대화 수**: 실시간 업데이트
- **검색/직접 비율**: 라우팅 통계
- 사용 패턴 분석

### 5. 예제 질문
- **검색 필요 질문**: 4개 예제
- **직접 답변 질문**: 4개 예제
- **원클릭 입력**: 버튼 클릭으로 질문 자동 입력

### 6. 대화 관리
- **대화 초기화**: 전체 히스토리 삭제
- **상태 유지**: 세션 간 데이터 보존

## 🎨 디자인 요소

### Custom CSS
- **채팅 메시지 스타일**:
  - 사용자: 파란색 테마
  - AI: 회색 테마
- **Route Badge**: 동적 색상
- **검색 결과 카드**: 주황색 강조
- **메트릭 카드**: 깔끔한 회색 배경

### 반응형 레이아웃
- **2-컬럼 예제**: 검색/직접 질문 나란히 표시
- **사이드바**: 접을 수 있는 설정 패널

## 🚀 성능 최적화

### 세션 상태 관리
- **캐싱**: RAG 인스턴스 재사용
- **효율적 상태**: 최소한의 데이터만 저장

### 에러 핸들링
- **Graceful Degradation**: 에러 시 사용자 친화적 메시지
- **재시도 메커니즘**: 실패 시 자동 재시도 지원

## 📱 사용자 경험

### 직관적 인터페이스
1. **첫 화면**: 예제 질문으로 시작
2. **채팅 입력**: 자연어로 질문
3. **즉시 답변**: 빠른 응답
4. **결과 탐색**: 검색 결과 상세 확인

### 피드백
- **로딩 인디케이터**: "답변 생성 중..."
- **성공/에러 메시지**: 명확한 상태 표시
- **통계 업데이트**: 실시간 반영

## 🔧 개발자 기능

### 디버그 모드
- **워크플로우 추적**: 각 노드 실행 확인
- **State 검사**: 중간 상태 확인
- **성능 분석**: 실행 시간 측정

### 확장 가능성
- **모듈화**: 각 기능 독립적
- **커스터마이징**: CSS/테마 쉽게 변경
- **API 통합**: 외부 서비스 연결 용이
