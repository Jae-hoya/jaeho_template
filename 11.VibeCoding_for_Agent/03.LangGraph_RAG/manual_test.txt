================================================================================
LangGraph RAG Streamlit 앱 실행 가이드
================================================================================

✅ 모든 검증이 완료되었습니다!

다음 명령어로 앱을 실행하세요:

    streamlit run streamlit_app.py

브라우저가 자동으로 http://localhost:8501을 엽니다.

================================================================================
테스트 시나리오
================================================================================

1. 검색 질문:
   "의사 전용 대출 상품 추천해줘"
   → 검색 결과 3개 표시, SEARCH 배지

2. 직접 답변:
   "안녕하세요"
   → 인사 답변, DIRECT 배지

3. 디버그 모드:
   사이드바에서 "디버그 모드" 토글 → 워크플로우 로그 확인

4. 통계:
   사이드바에서 총 대화 수, 검색/직접 비율 확인
