Python으로 MCP server 구현:
- 프로젝트명: calculate-mcp-server
- 기능:
  1. add tool: 두 숫자를 더하기
  2. multiply tool: 두 숫자를 곱하기
  3. 위와 같은 방식으로, 뺄셈, 나눗셈도 도구도 추가
  4. 각 연산마다 디버깅 정보를 stderr로 출력
- 구현:
  - mcp 패키지 사용
  - stdio 통신
  - 각 tool은 inputSchema로 파라미터 정의
  - 연산 전후로 디버깅 로그 출력
